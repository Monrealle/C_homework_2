# DFA (Детерминированный конечный автомат)

Программа распознаёт, является ли введённая строка числом (целым, дробным или в научной нотации с `E`/`e`), используя детерминированный конечный автомат.

## Сборка

```bash
git clone https://github.com/Monrealle/C_homework_2
cd C_homework_2/src/DFA
mkdir build && cd build
cmake ..
make

В результате в папке build появится исполняемый файл dfa.

## Использование
./dfa
Ввод: Введите строку: 123.45E-6
Результат: Это число!

## Тестирование
./test_dfa
Результат: Вывод проверок корректных и некоректных чисел.
